# OmegaT — Brukermanual

Et tastaturførst arbeidssted for oversettelsesminner, glossarer og merkede dokumenter.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `no`.

1. Åpne — `omegat.project`
2. Nytt — Språk for kilderfiler:, Språk for oversatte filer:, Aktiver segmentering på setningsnivå
