# OmegaT — Používateľská príručka

Klávesnicová pracovná stanica pre prekladovú pamäť, glosáre a označené dokumenty.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `sk`.

`source/` · `target/` · `omegat/project_save.tmx` · `tm/` · `glossary/` · `dictionary/`

- Uložiť (`Ctrl+S`)
- Vytvoriť preložené dokumenty (`Ctrl+D`)
