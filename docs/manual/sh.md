# OmegaT — Priručnik za korisnike

Radna stanica usmerena na tastaturu za prevodilačku memoriju, glosare i označene dokumente.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `sh`.
