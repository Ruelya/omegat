# OmegaT — Doracaku i shfrytëzuesit

Stacion pune me përparësi tastierën për kujtesa përkthimi, glossarë dhe dokumente me etiketë.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `sq`.

## Krijo / Hap

1. Hap — `omegat.project`
2. Krijo — Gjuha e Skedarëve burimor:, Gjuha e skedarëve të përkthyer, Aftëso segmentimin në nivel fjalie

`source/` · `target/` · `omegat/project_save.tmx` · `tm/` · `glossary/` · `dictionary/`
