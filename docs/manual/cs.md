# OmegaT — Uživatelská příručka

Klávesnicová pracovní stanice pro překladovou paměť, glosáře a označené dokumenty.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `cs`.
