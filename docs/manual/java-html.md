# Java HTML manual

The long-form OmegaT 6.2 user guide (DocBook) remains in `reference/java/src/docs/manual/` and the last generated HTML tree under `reference/java/release/`. This rewrite ships Markdown under `docs/manual/` (`en.md`, `zh-CN.md`) as the packaged Help set. Open the Java HTML locally when you need a chapter that has not been ported yet. Do not delete `reference/java` while any STATUS row still needs it; after R8 there are no `scaffold` rows, but the tree stays as the golden source.
