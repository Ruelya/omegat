# OmegaT — Manual d'usuari

Estació de treball centrada en el teclat per a memòries, glossaris i documents etiquetats.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `ca`.

1. Obre — `omegat.project`
2. Crea — Llengua dels fitxers d'origen:, Llengua dels fitxers traduïts:, Segmentació per frases

- Desa (`Ctrl+S`)
- Crea els fitxers traduïts (`Ctrl+D`)
