# OmegaT — 使用手冊(U)

面向譯者的鍵盤優先工作站：翻譯記憶、詞彙表與帶標籤文件。

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `zh-TW`.

## 建立新專案(N) / 開啟舊專案(O)

1. 開啟舊專案(O) — `omegat.project`
2. 建立新專案(N) — 原文語言(S)：, 譯文語言(T)：, 啟用句子階層分節(N)

`source/` · `target/` · `omegat/project_save.tmx` · `tm/` · `glossary/` · `dictionary/`

- 儲存專案(S) (`Ctrl+S`)
