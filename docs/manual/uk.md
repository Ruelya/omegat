# OmegaT — Посібник користувача

Клавіатурна робоча станція для пам’яті перекладів, глосаріїв і розмічених документів.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `uk`.

## Новий / Відкрити

1. Відкрити — `omegat.project`
2. Новий — Мова оригіналу:, Мова перекладу:, Сегментація за реченнями

`source/` · `target/` · `omegat/project_save.tmx` · `tm/` · `glossary/` · `dictionary/`

## Область редагування

- Зберегти (`Ctrl+S`)
- Створити перекладені файли (`Ctrl+D`)
- Шукати / Замінити
- До наступного сегмента / До попереднього сегмента
- Автодоповнення: Глосарій, Налаштування автотексту, Таблиця символів, Доповнення зі збереженого, Прогнозовані доповнення зі збереженого

Файли для перекладу, Нечіткі збіги, Глосарій, Словник, Машинний переклад, Примітки, Коментарі, Highlight Segments with Alternative Translation, Властивості
