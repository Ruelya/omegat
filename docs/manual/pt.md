# OmegaT — Manual do utilizador

Estação de trabalho centrada no teclado para memórias, glossários e documentos etiquetados.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `pt`.
