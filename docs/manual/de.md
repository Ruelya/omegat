# OmegaT — Bedienungsanleitung

Eine tastaturgeführte Arbeitsstation für Translation Memory, Glossare und markierte Dokumente.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `de`.
