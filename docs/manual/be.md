Клавіятурная рабочая станцыя для памяці перакладаў, гласарыяў і размечаных дакументаў.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `be`.
