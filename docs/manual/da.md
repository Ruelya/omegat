# OmegaT — Brugervejledning

En tastaturførst arbejdsstation til oversættelseshukommelser, glossarer og mærkede dokumenter.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `da`.
