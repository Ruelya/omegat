# OmegaT — Εγχειρίδιο Χρήστη

Σταθμός εργασίας με προτεραιότητα το πληκτρολόγιο για μνήμες, γλωσσάρια και ετικετοποιημένα έγγραφα.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `el`.

## Νέο / Άνοιγμα

1. Άνοιγμα — `omegat.project`
2. Νέο — Γλώσσα Αρχείων προέλευσης:, Γλώσσα Μεταφρασμένων αρχείων, Ενεργοποίηση κατάτμησης σε επίπεδο πρότασης

`source/` · `target/` · `omegat/project_save.tmx` · `tm/` · `glossary/` · `dictionary/`
