# OmegaT — Podręcznik użytkownika

Stacja robocza sterowana klawiaturą: pamięć tłumaczeń, glosariusze i dokumenty z tagami.

## Install

- Linux: deb / rpm / tar.gz (OmegaT)
- Windows: NSIS
- macOS: DMG

OmegaT sidecar: `omegat-sidecar`. UI locale: `pl`.
